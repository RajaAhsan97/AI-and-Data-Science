Django Polling App Tutorial - For Beginners

-------------------------------------------------------------------------------------------------------------
Step 1: Creating a virtual environment: A virtual environment keeps all the packages for your project in one 
		place, so they don’t conflict with other projects. (Recommended for Each project)
		
	python -m venv <your_environment_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 2: Activate your virtual environment:

	<your_environment_name>\Scripts\activate
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 3: Install Django in virtual environment

	pip install django
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 4: Creating a Project in Django
	django-admin startproject <your_project_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 5: Set path to your django project
	cd <your_project_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 6: Creating app in Django project
	python manage.py startapp polls
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 7: make migrations
	python manage.py makemigrations
	python manage.py migrate
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 8: run server
	python manage.py runserver
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 8: Add your app to INSTALLED_APPS in settings.py file
	INSTALLED_APPS = [
		# default apps
		"polls"
	]
	
Django's Default TEMPLATE setting has "APP_DIRS=TRUE"  --> templates places in polls/templates/polls/

Step 12: create poll/urls.py
add this code in urls.py
===========================================================================
	from django.urls import path
	from . import views

	app_name = 'polls'
	urlpatterns = [
		path('', views.index, name='index'),
		path('<int:question_id>/', views.detail, name='detail'),
		path('<int:question_id>/results/', views.results, name='results'),
		path('<int:question_id>/vote/', views.vote, name='vote'),
	]
===========================================================================

include polls urls for project poll_project/urls.py

===========================================================================
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('polls/', include('polls.urls')),
    path('admin/', admin.site.urls),
]
===========================================================================
