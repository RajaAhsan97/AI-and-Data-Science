Django project setup Tutorial - For Beginners

-------------------------------------------------------------------------------------------------------------
Step 1: Creating a virtual environment: A virtual environment keeps all the packages for your project in one 
		place, so they don’t conflict with other projects. (Recommended for Each project)
		
	python -m venv <your_environment_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 2: Activate your virtual environment:

	<your_environment_name>\Scripts\activate
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 3: Install Django in virtual environment

	pip install django
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 4: Creating a Project in Django

	django-admin startproject <your_project_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 5: Set path to your django project

	cd <your_project_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 6: Creating app in Django project

	python manage.py startapp <your_app_name>
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 7: make migrations

	python manage.py makemigrations
	python manage.py migrate
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 8: Add your app to INSTALLED_APPS in settings.py file of your project directory
	INSTALLED_APPS = [
		# default apps
		"polls"
	]

-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 10: open views.py file of your app and add this code in it.

	from django.http import HttpResponse
	
	# 
	def index(request):    # you can use any other function name
		return HttpResponse("Welcome...")
	
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 11: Now create urls.py file in your app (i.e. polls) and write this code in it

	from django.urls import path
	from . import views         # It means that from your app folder import views.py file
	
	app_name = "polls"
	
	urlpatterns = [
		path("index/", views.index, name="index")
	]
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 12: Now you have to include your app urls into your project urls 
		 Open urls.py file of your project and modify the code to this

	from django.contrib import admin
	from django.urls import path, include
	
	urlpatterns = [
		path("admin/", admin.site.urls)
		path("", include("polls.urls"))
	]
	
	Note: include("polls.urls") --> means to include urls.py file into your project
-------------------------------------------------------------------------------------------------------------


-------------------------------------------------------------------------------------------------------------
Step 13: Now run your django server from terminal by using this command
	
	python manage.py runserver 
-------------------------------------------------------------------------------------------------------------

-------------------------------------------------------------------------------------------------------------
Step 14: Copy the url from your terminal --> Open your browser paste url in it
	
	http://127.0.0.1:8000/admin/    --> This will open default administration panel of django
	
	http://127.0.0.1:8000/index/    --> This will open the page displaying "Welcome" 
-------------------------------------------------------------------------------------------------------------
